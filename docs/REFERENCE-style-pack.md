## 4. 抽取一条母题的判据（避免把素材包抄成一堆死代码）

一条素材包的动效，值得抽进 `src/kit/motifs/` 的条件是**三条同时成立**：

1. 它描述的是一**个数学对象**（不是一种氛围）——例如「字散成粒子再聚成另一句」= 两组点集之间的插值；
2. 至少 **3 条**素材包条目和它同源（说明它是通用母题，不是某个片子的私货）；
3. 抽出来之后，新片子只写参数（如 `{ from: [...], to: '...' }`），不写数学。

按这三条，下一批值得抽的是：**字散再聚**（A5 / M3 / M25 / M38）、**图表的生长**（F1 / L40 / X 系列的数字栏）、
**关系图**（F2 / L5 视觉调查）。**不值得抽的**：老胶片（G1）、信号故障（G2）—— 它们是后处理参数，已经能表达。
