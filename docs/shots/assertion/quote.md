# `quote` · 引言镜头：眉标逐字打出 + 一条生长的竖线 + 大段引文逐行上浮 + 出处署名淡入（align: left 是左侧竖线 + 排印引号，center 是居中 + 上方短横线）。

> 分类：**主张** · 能量 低

引文的字号按**最长那一行**的视觉长度自动分档（CJK 算 1、拉丁与数字算 0.55：<=12 给 92px、<=18 给 78、<=26 给 64、<=36 给 52、更长 42）—— 不是按总字数：写了换行时决定溢不溢出的永远是那最长的一行。所以同一个 text 在任何段长下字号都一样；想强制断行就在 text 里写反斜杠 n。⚠ 切进来的**头 0.5 秒画面几乎只有背景**（引文第一行 t=0.5 才起步、眉标 0.15s 才开始打字）——硬切到这里会看到半秒空场（`anim cuts` 的接触表上看得一清二楚）；要和上一段接得紧就写 overlap 0.5，或者让上一段多留半秒。⚠ 引文超过 4 行时"一屏几块字"会超过 6 块的软上限（docs/LAYOUT.md），check 的版面守门会 warn —— 那是读数不是错误。背景是本模板自带的整帧 Pass（key shot_quote_bg），所以它自己铺满整帧，不需要时间线的 world，也不能和别的模板叠在同一段。

## 什么时候用

引用一句话（人物 / 文档 / 结论），需要出处署名

## 什么时候别用

引文超过约 4 行；把旁白原句逐字抄进画面（lint-narration-dup 会点名）

## 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | `"quote"` | 段名（HUD / --only / 报错里用它） |
| `label` | string | `"NOTE"` | 左上眉标（等宽小字，逐字打出；空串则不画） |
| `text` | string | `"把每一帧写成时间的函数，\n画面就成了一道可以求解的方程。"` | 引文（反斜杠 n 是强制断行；过长自动折行且字号自动分档） |
| `cite` | string | `"anim · 设计手记"` | 出处署名（引文块下方，整行淡入） |
| `role` | string | `"确定性渲染"` | 署名的第二段（更小更暗；空串则不画） |
| `align` | string | `"left"` | 'left'（默认：左侧竖线 + 排印引号）或 'center'（居中 + 上方短横线） |

## 最小示例

```js
export default shot('quote', { label: "NOTE", text: "把每一帧写成时间的函数，\n画面就成了一道可以求解的方程。", cite: "anim · 设计手记" });
```
