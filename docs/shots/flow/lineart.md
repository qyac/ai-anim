# `lineart` · 一笔线稿：一条折线按弧长自己画出来，走过的节点留小圆点与刻度，笔尖带一个信号色光点与当前节点的名字（幽灵线先铺出全貌）。

> 分类：**流程** · 能量 中低

背景是自带的整帧 Pass（key `shot_lineart_bg`），不需要时间线的 world。`points` 是**归一化**坐标（0..1，成对出现），按内容框映射 —— 换画幅不用重算数字。`labels` 用 `|` 分隔，按顺序对到节点；节点数多于标签时多出来的节点不标名字。画线用的是**弧长**（`polylineLengths` / `pointAtLength`），不是点数 —— 否则长段走得快、短段走得慢。它不画坐标轴、不标数值：要比高低用 `chart`，要读一个数用 `counter`。

## 什么时候用

流程 / 时间线 / 路径 / 生长曲线 —— 一件事接一件事的**形状**

## 什么时候别用

需要读出具体数值或比较高低时（改用 chart / counter）；节点超过 7 个时名字会挤在一起

## 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | `"lineart"` | 段名（HUD / --only / 报错里用它） |
| `kicker` | string | `"LINEART / 一笔线稿"` | 左上眉标 |
| `points` | number[] | `[0.05,0.78,0.27,0.55,0.46,0.66,0.66,0.36,0.84,0.46,0.97,0.2]` | 归一化坐标（0..1，x,y 成对）；长度不足 4 或奇数时退回默认路径 |
| `labels` | string | `"采集|清洗|建模|校验|发布"` | 节点名字，用 | 分隔，按顺序对到节点（空串则不标名字） |
| `footer` | string | `"一步接一步 —— 走过的节点留在原地"` | 底部一行（页脚带里，最后淡入；空串则不画） |

## 最小示例

```js
export default shot('lineart', { kicker: "LINEART / 一笔线稿", points: [0.05,0.78,0.27,0.55,0.46,0.66,0.66,0.36,0.84,0.46,0.97,0.2], labels: "采集|清洗|建模|校验|发布" });
```
