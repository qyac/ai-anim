# `chart` · 柱状图逐条生长：坐标轴 + 刻度 + 排线柱体 + 扫描线与跟随读数

> 分类：**数据** · 能量 中

背景是本模板自带的整帧纸面 Pass（key `demo_chart_paper`），所以它自己铺满整帧，既不需要时间线的 world，也不能和别的模板叠在同一段。values 改长度后 `sub` 里的 "n = 12" 不会跟着变（它是纯文本参数）；`peak` 是判"最高那根"的阈值（上信号色 + 顶端小帽用信号色）。

## 什么时候用

一屏一组可比的量（3–8 根柱），让观众看出谁高谁低

## 什么时候别用

超过 8 个值、或需要精确读小数时改 counter；没有出处的数字不要画

## 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | `"chart"` | 段名（出现在 HUD、--only、报错里） |
| `values` | number[] | `[0.18,0.34,0.27,0.52,0.44,0.71,0.63,0.88,0.79,0.95,0.86,1]` | 每根柱子的值（0..1；默认 12 个，与 demo 一致） |
| `title` | string | `"每次迭代的最高准确率"` | 图上方的主标题（逐字入场） |
| `sub` | string | `"PER-RUN  ·  n = 12  ·  纯代码绘制，无图片素材"` | 标题下的等宽副标题（默认文案里的双空格是刻意的） |
| `footer` | string | `"确定性渲染 → 任意时刻可重放，任意精度可重渲"` | 底部结论（最后才淡入） |
| `peak` | number | `0.95` | 判"最高"的阈值：>= peak 的柱子用信号色 |

## 最小示例

```js
export default shot('chart', { values: [0.18,0.34,0.27,0.52,0.44,0.71,0.63,0.88,0.79,0.95,0.86,1], title: "每次迭代的最高准确率", sub: "PER-RUN  ·  n = 12  ·  纯代码绘制，无图片素材" });
```

## 看效果

```sh
node scripts/anim.mjs shots chart                        # 参数全表（唯一权威）
node scripts/anim.mjs still demo -t 2 --only chart      # 出图看
```
