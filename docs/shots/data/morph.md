# `morph` · 图表形变：一组数先当柱子立起来，再收成一条折线，最后在折线下面铺出排线面积 —— 同一组数换三种画法，位置不变。

> 分类：**数据** · 能量 中

背景是自带的整帧 Pass（key `shot_morph_bg`），不需要时间线的 world。三个相位：p0 0.30→1.90s 柱子长高 / p1 1.60→3.00s 收成折线 / p2 2.60→4.00s 铺面积。段长不足约 4 秒会停在半路（那也算"没演完"，不是 bug）。数据点的 x 三个相位共用，形变时位置不跳 —— 这是它与 `chart` 的分工：`chart` 只比高低，`morph` 讲"换一种呈现"。⚠ 画面上的数要有出处（docs/FACTS-TEMPLATE.md ★）；默认值只是示意读数。

## 什么时候用

讲"同一件事换一种呈现" —— 柱看高低、线看趋势、面积看累积

## 什么时候别用

只需要比高低时（chart 更省）；数值需要精确读数时（counter）

## 参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | `"morph"` | 段名（HUD / --only / 报错里用它） |
| `values` | number[] | `[0.22,0.38,0.31,0.55,0.48,0.66,0.72,0.61,0.86]` | 每个数据点的值（0..1）；长度 = 点数（少于 2 个按 2 个算） |
| `title` | string | `"同一组数，换三种画法"` | 图上方的主标题（逐字上浮） |
| `sub` | string | `"BAR → LINE → AREA  ·  位置不变，只换呈现"` | 左上眉标（等宽小字；落在页眉保留带里） |
| `footer` | string | `"柱看高低 · 线看趋势 · 面积看累积"` | 底部一行（页脚带里，最后淡入；空串则不画） |

## 最小示例

```js
export default shot('morph', { values: [0.22,0.38,0.31,0.55,0.48,0.66,0.72,0.61,0.86], title: "同一组数，换三种画法", sub: "BAR → LINE → AREA  ·  位置不变，只换呈现" });
```

## 看效果

node scripts/anim.mjs shots morph                        # 参数全表（唯一权威）
