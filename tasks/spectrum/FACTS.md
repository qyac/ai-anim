# FACTS —— 《把信号拆开》画面数字的出处

> 规则（`AGENTS.md` §10.11）：**画面上的每个字面量数字都要能在这里找到出处**，找不到就写成占位符。
> 这支片子是纯数学演示，所以绝大多数"数字"是**算出来的**、不是查来的 —— 对这类数字，
> 出处就是"用哪个公式算的、在哪个文件哪一行"。

## 2. 算出来的东西（不是查来的）

| 画面上的形状 | 使用的公式 | 代码位置 |
|---|---|---|
| 方波 | `f(t) = Σ_{n 奇} (4/πn) sin(nt)` —— 方波的标准傅里叶级数 | `scenes/_kit.js` 的 `squareCoeffs` / `squareWave` |
| 圆链 | 每一项一圈，半径 = 该谐波系数 `4/(πn)`，旋转速度 = `n` | `scenes/_kit.js` 的 `chain` |
| DCT 频率图 | 二维 DCT-II，归一化系数 `0.25·c(u)·c(v)`（`c(0)=1/√2`，否则 1） | `scenes/image.js` / `scenes/keep.js` 的 `dct2` |
| 重建图 | 二维 IDCT（DCT-III），与上式互逆 | `scenes/keep.js` 的 `idct2` |
| 采样重建 | 采样点之间直接连直线（零阶保持/线性插值），这就是"不足采样"会看到的假波 | `scenes/sample.js` |

## 3. 刻意没写的东西（及原因）

| 没写 | 为什么 |
|---|---|
| 任何"压缩率 / 省了多少字节"的数字 | 这支片子没有真做一次 JPEG 编码，报一个压缩率就是编的。要做必须有实测 |
| 任何"人类听不到 20kHz 以上"这类生理数字 | 与本片论点无关（本片讲的是采样不足会产生假频率，不是听觉范围） |
| 具体的历史年份 / 人名 | 纯原理解释，不涉及人物；硬加会显得像凑数 |
| 频谱柱的绝对数值（dB） | `music.at()` 给的是 0–1 归一化包络，不是 dB SPL。标成 dB 就是假精度 |

## 3.5 算出来的值（判据 ③：静态查不到等于几）

```sh
node tools/lint-fabricated-numbers.mjs spectrum   # 数值显示位是否有出处
node tools/lint-narration-dup.mjs spectrum        # 画面有没有复述旁白
```

两个都是交付前必跑（`AGENTS.md` §10.9 / §10.11）。

## 5. 算出来的值的口径（lint 判据 ③ 会点名的那几处）

| 位置 | 口径 |
|---|---|
| `series.js` 的 `k` 读数 | `growK(t, 6.4, 40)` → `round`，范围 1..40。它 = 当前画了几个谐波，随段内时间长满 |
| `sound.js` 的频谱柱高 | `music.at(t + j×0.13)` 的 `low/mid/high` 归一化包络，范围 0..1（下限夹到 0.05，否则柱高会是 0 看不见） |
| `sample.js` 的采样点数 | `round(cases[].hz × 3.0)`（画 3 个周期），hz 是写死的 |
