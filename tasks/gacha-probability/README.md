# 抽卡与十连不中 · 合成素材

主对比统一采用 **20% 长期命中率**。一次抽卡只记「中目标」或「未中目标」。表中的事件是从指定起点出发，接下来十抽全部未中。

| 机制 | 本轮起点 | 从长期序列随机挑一个起点 |
| --- | ---: | ---: |
| 每抽独立，命中率 20% | 10.7374% | 10.7374% |
| 每袋 10 张，固定 2 张命中，袋内洗牌后无放回 | 0%（新袋第一张） | 2.2815%（可以跨袋） |
| 线性 PRD，长期命中率 20% | 1.9491%（计数重置后） | 0.6082% |

## 计算模型

- **每抽独立。** 过去不中的次数不改变下一抽的命中率。指定的连续 (k) 抽全不中为 `(1 - p)^k`。20% 的例子里，五连不中是 **32.768%**，十连不中是 **10.7374%**。
- **固定袋与 Fisher–Yates。** 从尾部到开头逐个处理卡位，每步在 `0…i` 中等概率选 `j`，交换 `i` 和 `j`。每个排列有同样的概率。抽取时若用一个含 2 张命中卡、8 张未中卡的袋，开袋后的固定十抽必含两张命中卡。跨袋最长仍可有 **16 次**连续未中。每袋单独洗牌，用完才补新袋。 [Durstenfeld，Algorithm 235](https://doi.org/10.1145/364520.364540)
- **线性 PRD。** 上次命中后重置，从 `N=1` 开始。第 `N` 抽的命中概率是 `min(1, C*N)`，连续 (k) 抽全不中是 `S(k) = ∏_{n=1…k}(1 - min(1, C*n))`。平均等待抽数为 `E[T] = ∑_{k≥0}S(k)`，长期命中率为 `1/E[T]`。用二分法反求 (C)。目标 20% 时，`C≈0.05570404`，首抽命中率是 **5.57%**，第十抽在前九抽都不中时的命中率是 **55.70%**，第 **18** 抽必出，最多 **17** 连不中。
- **起点口径。** 重置后十连与长期序列中随机抽一段，是两个事件。PRD 在长期随机起点的概率为 `∑_{j≥k}S(j)/E[T]`。固定袋则对袋内 10 个起点取平均，并按跨袋边界分段。若问「玩了很多抽，期间至少遇到一次十连不中」，还需要给出总抽数。

## 可用文件

| 文件 | 内容 |
| --- | --- |
| `probability.mjs` | 独立抽卡、固定袋、Fisher–Yates、线性 PRD、长期随机起点的无依赖函数 |
| `data/curves-20pct.csv` | 两种起点的全不中曲线，以及给定此前全不中时的下一抽命中率。概率用 0 到 1，空值表示条件事件概率为零 |
| `data/summary.json` | 5%、10%、20% 三组的五连、十连数据、PRD 常数和上限。20% 组另有固定袋数据。在 5% 和 10% 组，PRD 从重置开始的十连不中概率高于独立抽卡 |
| `data/fisher-yates-steps.json` | 一组事先指定的合法交换及每步卡片顺序，索引从 0 开始。可按步骤任意取帧。其中命中卡带编号，便于看出交换动作 |
| `svg/miss-tail.svg` | 从新袋、重置或独立十连起点出发，连续 (k) 抽全不中的曲线 |
| `svg/next-hit.svg` | 给定此前各抽都未中，第 (N) 抽的命中率。固定袋曲线在第 9 抽结束，该抽必出 |
| `svg/ten-misses.svg` | 同为 20% 长期命中率时，十连不中在两种起点口径下的对照 |
| `svg/card-hit.svg`、`svg/card-miss.svg` | 命中与未中卡片图标。SVG 均为透明背景，配色适合深色画布 |

洗牌算法均匀排列已有卡片。将「独立抽取」变成「每袋固定张数」的是配置固定命中卡数量、袋内无放回的抽取规则。PRD 则依赖上次命中以来的计数。比较图呈现的是这三种抽取规则下的理论概率。
