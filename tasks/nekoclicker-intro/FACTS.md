## 2. 刻意没写的东西（及原因）

- **不写代码行数、包体大小、下载量、星数**：仓库里没有可引用的实测数字，编一个的成本是零。
- **不写「271 条前端冒烟 / 65 条 API 测试」**：它们真实存在（`STATUS.md`），但同屏放三个计数会把 602 的份量稀释掉；
  一支 45 秒的介绍片只讲一件事：「一个零依赖的框架 + 它被测到位」。要展开再单开一支。
- **不写具体游戏内容（猫娘咖啡馆的玩法）**：那是内容包的叙事，介绍片只讲框架本身。
- **不写性能/帧率**：没有本轮实测，写出来就是猜。

## 3. 名词口径

- 「增量游戏」= incremental / idle game（点击 + 放置 + 累计产出）。中文里也叫「放置游戏」；片子里统一用**增量**。
- 「内容包」= 一套数据（建筑 / 升级 / 成就 / 剧情 / 纪元），不含引擎代码；换包不换引擎。
- 「公开 API 只增不改」= 从 1.0.0 起的兼容承诺，由快照测试守着（`engine/docs/VERSIONING.md`）。
